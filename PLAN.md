# Timepass build plan

## Scope
Build an Indian-context browser playground inspired by Neal.fun's low-friction game shelf. Launch eight complete experiences, create a dedicated GitHub repository, and publish on GitHub Pages like Terms Apply.

## Launch experiences
| Experience | Main action | Finish/replay |
| --- | --- | --- |
| City Tycoon | Roll, buy Indian city properties, collect rent against a computer opponent | 16 rounds or bankruptcy; score net worth; restart |
| Spend a Crore | Buy and sell a fictional basket from chai to a flat with ₹1,00,00,000 | Exhaust budget; receipt; reset |
| Gully Cricket | Time six shots at a moving ball marker | Six-ball score and replay |
| Chai Tapri | Match five customer orders with ingredients | Tips, order feedback, replay |
| Bargain Bazaar | Negotiate three fictional bazaar purchases | Three rounds, budget and savings, replay |
| Dabba Memory | Find six matching pairs of lunch items | Move count, complete state, shuffle |
| Perfect Roti | Draw a closed circle on a tawa | Roundness score; keyboard alternative; retry |
| Train Window | Watch a procedural countryside pass a train window | Day/evening, speed, pause; no finish |

## Delivery sequence
1. Inspect the current reference catalog and existing deployment pattern.
2. Record product direction and design: illustrated tiles, compact masthead, direct entry.
3. Build dependency-free app, original vector scenes, accessible controls and hash routing.
4. Test economic invariants, win/loss states, every main control, keyboard and mobile layouts.
5. Commit original source to a dedicated GitHub repository; deploy through GitHub Actions.
6. Verify deployment status and live content. Return site and repository links.

## Design and content boundaries
No copied images, source code, brand identity, or unsupported cultural/factual claims. Fictional prices are labeled. A working About & data page explains browser storage and hosting boundaries. No invented legal agreement. The reference inspires the browsing pattern and simplicity.

## Later releases
Train booking puzzle, Indian language wordplay, a sourced India scale explainer, a city map challenge, a spice-combination sandbox, and an escalating form puzzle. These need separate design/data work; none appears as a playable tile until implemented.

## Release 1.1

Add three original experiences to the existing shelf without changing its visual system. Seat, Please has five solvable, fictional train-seat puzzles. Masala Lab has eight starting ingredients and 21 discoverable combinations. Society Pass reveals ten cumulative rules for an invented visitor message.

Ship a deterministic build with content-hashed JavaScript and CSS, including dependency hashes, to keep returning visitors on matching assets. Preserve existing local scores; extend the About & data clearing control to cover kitchen discoveries. Test the new rules and build behavior, check desktop and phone rendering, then publish through the existing Pages workflow.
